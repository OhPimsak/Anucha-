# ระบบจัดการเรียนรู้ (LMS) — ผศ.ดร.อนุชา พิมศักดิ์

ระบบจัดการเรียนรู้ออนไลน์ (Learning Management System) สำหรับรายวิชาที่สอนโดย
**ผศ.ดร.อนุชา พิมศักดิ์** (Asst. Prof. Dr. Anucha Pimsak) ครอบคลุมการแสดงรายวิชา
เนื้อหาบทเรียน แบบฝึกท้ายบท และการติดตามความก้าวหน้าของผู้เรียน

เว็บแอปนี้เป็น **static web app** ล้วน (HTML/CSS/JavaScript) ไม่ต้องใช้เซิร์ฟเวอร์
หรือฐานข้อมูล — เปิดใช้งานได้ทันทีในเบราว์เซอร์ และทำงานแบบออฟไลน์ได้

## คุณสมบัติ

### ส่วนการเรียนรู้ (LMS)
- 📚 **แคตตาล็อกรายวิชา** — แสดงรายวิชาพร้อมรหัส ระดับ หน่วยกิต และความก้าวหน้า
- 📖 **บทเรียน** — เนื้อหาแบ่งเป็นโมดูล/บทเรียน อ่านง่าย
- ✅ **ติดตามความก้าวหน้า** — ทำเครื่องหมายบทเรียนที่เรียนจบ คำนวณ % อัตโนมัติ
- 📝 **แบบฝึกท้ายบท** — คำถามปรนัยพร้อมเฉลยและคำอธิบาย
- 👤 **หน้าผู้สอน** — ประวัติและสาขาความเชี่ยวชาญ

### ส่วนระบบ CA — บริหารจัดการการเรียนการสอนแบบ OBE
ระบบประเมินผลรายวิชา (Course Assessment) ที่เชื่อม **PLO → CLO → Skill** ของหลักสูตร
เข้ากับการกรอกคะแนนและการตัดเกรดอัตโนมัติ **รองรับหลายรายวิชา** (อิงโครงสร้างจากแฟ้ม `KSU_CA_ED002905`)

- 🗂️ **หลายรายวิชา** — สลับรายวิชาได้จากตัวเลือกด้านบน แต่ละวิชามี CLO/น้ำหนัก/นักศึกษา/รายงานแยกกัน
  มาพร้อม 4 รายวิชาของ ผศ.ดร.อนุชา พิมศักดิ์:
  - `ED-002-905` การพัฒนาหลักสูตรและการประกันคุณภาพการศึกษา (ข้อมูลจริง 33 คน)
  - `ED-002-904` การออกแบบและพัฒนาหลักสูตร ระดับอุดมศึกษา
  - `ED-002-906` การจัดการเรียนรู้ภาษาไทย
  - `ED-002-907` นวัตกรรมการจัดการเรียนรู้เพื่อการพัฒนาที่ยั่งยืน
- ➕ **เพิ่มรายวิชาเองได้** — เมนู “+ เพิ่มรายวิชา” มีฟอร์มสร้างรายวิชาใหม่ (กรอกข้อมูลวิชา + กำหนด CLO และองค์ประกอบการประเมิน)
  รายวิชาที่เพิ่มถูกบันทึกใน localStorage แก้ไข/ลบได้ภายหลัง (รายวิชาตั้งต้นลบไม่ได้)
- 🎯 **ภาพรวมรายวิชา (CA)** — PLO ของหลักสูตร และแผนการสอนรายสัปดาห์ที่จับคู่ CLO/Skill/ระดับ/วิธีประเมิน/กิจกรรม
- 📊 **เกณฑ์การบรรลุ CLO** — องค์ประกอบการประเมินและสัดส่วนคะแนนของแต่ละ CLO
- ⚙️ **ตั้งค่า** — น้ำหนัก CLO (รวม = 1.00), เกณฑ์ผ่านราย CLO, เลือกสเกลการตัดเกรด 3 แบบ
  (มาตรฐาน A≥85% / เข้ม A≥90% / ผ่อนปรน A≥80%) และเลือก **วิธีกรอกคะแนน** (ระดับ CLO หรือระดับองค์ประกอบย่อย)
- ✍️ **กรอกคะแนน** — รองรับ 2 โหมด:
  - **ระดับ CLO** — กรอกคะแนน CLO% โดยตรง
  - **ระดับองค์ประกอบย่อย** — กรอกคะแนน Quiz/ชิ้นงาน/อัตนัย/นำเสนอ แล้วระบบ **รวมเป็น CLO% อัตโนมัติ**
    ตามน้ำหนักองค์ประกอบ (คำนวณเมื่อกรอกครบทุกองค์ประกอบของ CLO นั้น)

  ทุกโหมดคำนวณ ผ่าน/ไม่ผ่าน, คะแนนรวมถ่วงน้ำหนัก และเกรดอัตโนมัติ · เพิ่ม/ลบนักศึกษาได้
- 📥 **นำเข้า/ส่งออก CSV** — **ส่งออก CSV** (รองรับภาษาไทยใน Excel) และ **นำเข้า CSV** เพื่ออัปโหลดคะแนนทีเดียว
  (จับคู่นักศึกษาด้วย Student_ID, คอลัมน์ `CLO1%`, `CLO2%`, …) · ถ้าต้องการนำเข้าจาก Excel ให้บันทึกเป็น `.csv` ก่อน
- 📈 **รายงานรายวิชา** — สรุป CLO Attainment (ค่าเฉลี่ย/อัตราผ่าน), การกระจายเกรด, GPA ชั้นเรียน และช่องบันทึก Reflection/CQI

> สูตรการคำนวณทั้งหมด (คะแนนรวม = Σ คะแนน CLO × น้ำหนัก, การรวมองค์ประกอบเป็น CLO%, การตัดเกรด, CLO attainment, GPA)
> ได้รับการตรวจสอบตรงกับค่าที่คำนวณไว้ในไฟล์ Excel ต้นฉบับทุกค่า (นักศึกษา 33 คน)

### ทั่วไป
- 💾 **บันทึกในเครื่อง** — ใช้ `localStorage` ข้อมูลทั้งหมดอยู่ในเครื่องผู้ใช้ ไม่ถูกส่งออกภายนอก
- 📱 **รองรับมือถือ** — ออกแบบ responsive

## การใช้งาน

### เปิดตรง ๆ
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที

### หรือรันผ่าน local server (แนะนำ)
```bash
# Python 3
python3 -m http.server 8000

# หรือ Node.js
npx serve .
```
จากนั้นเปิด <http://localhost:8000>

## โครงสร้างโปรเจกต์

```
.
├── index.html        # โครงหน้าหลักและการเชื่อมสคริปต์
├── css/
│   └── styles.css    # สไตล์ทั้งหมด (responsive) รวมสไตล์ระบบ CA
└── js/
    ├── data.js       # ข้อมูลผู้สอนและรายวิชา LMS
    ├── store.js      # จัดการความก้าวหน้าการเรียนใน localStorage
    ├── app.js        # ตรรกะ SPA + hash routing + การเรนเดอร์ LMS
    ├── ca-data.js    # ข้อมูลหลายรายวิชา (CA_COURSES) PLO/CLO/Skill/องค์ประกอบ/นักศึกษา (สกัดจาก Excel)
    ├── ca-store.js   # บันทึกการตั้งค่า/คะแนน/รายงาน รายวิชา ใน localStorage (multi-course)
    └── ca.js         # เครื่องคำนวณ OBE + กรอกระดับองค์ประกอบ + นำเข้า/ส่งออก CSV + หน้าจอทั้งหมด
```

## การเพิ่ม/แก้ไขรายวิชา

ระบบออกแบบให้ **ขับเคลื่อนด้วยข้อมูล** — แก้เฉพาะไฟล์ `js/data.js` เท่านั้น
โดยเพิ่มอ็อบเจกต์รายวิชาใหม่เข้าไปในอาร์เรย์ `COURSES` ตามรูปแบบที่มีอยู่
(ดูคอมเมนต์อธิบายโครงสร้างในไฟล์) ไม่ต้องแก้ไขตรรกะของแอป
